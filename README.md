# Secrela Web

Next.js (App Router) frontend for [Secrela](https://secrela.com) — marketing site + authenticated app.

## Quick start

```bash
cp .env.example .env.local
npm install
npm run dev
```

Open `http://localhost:3000`

## Environment

| Variable | Example |
|----------|---------|
| `NEXT_PUBLIC_API_URL` | `http://localhost:4000` (dev) or `https://api.secrela.com` (prod) |

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Development server |
| `npm run build` | Production build |
| `npm start` | Run production build |
